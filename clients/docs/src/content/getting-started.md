## Setup

[Sign up](https://www.mycadet.ai/account/signup) for **Cadet Cloud** and we can hatch and start managing your assistant for you in seconds.

Check out our **[Downloads](https://www.mycadet.ai/downloads)** page for installing Cadet across desktop, mobile and more!

For those looking to self host their own Cadet, install the CLI in your terminal:

```bash
npm install -g @mycadet/cli
cadet hatch
```

## Updates

Cadet checks for updates automatically in the background. When an update is available, you'll see a green update button in the top right corner of the app. You can install immediately or defer until later.
